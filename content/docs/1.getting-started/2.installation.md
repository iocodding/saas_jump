# Installation

## Prerequisites

- Node.js 20+
- pnpm (`npm install -g pnpm`)
- A [Supabase](https://supabase.com) account (free tier is fine)

## 1. Clone the repository

```bash
git clone git@github.com:iocodding/saas_jump.git
cd saas-jump
pnpm install
```

## 2. Create a Supabase project

1. Go to [supabase.com](https://supabase.com) and create a new project
2. Wait for it to finish provisioning (~1 min)
3. Go to **Project Settings → API** and copy:
   - **Project URL**
   - **anon / public** key
   - **service_role** key (keep this secret)

## 3. Run the database migration

In the Supabase dashboard, go to **SQL Editor** and paste the full contents of:

```
supabase/migrations/20240101000000_init.sql
```

Click **Run**. This creates the `profiles` and `projects` tables, all RLS policies, and the signup trigger.

## 4. Configure environment variables

Copy the example file and fill in your values:

```bash
cp .env.example .env
```

```ini
NUXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NUXT_PUBLIC_SUPABASE_KEY=your-anon-key
SUPABASE_SERVICE_KEY=your-service-role-key
NUXT_PUBLIC_APP_URL=http://localhost:3000
```

## 5. Configure Supabase Auth redirect URLs

In Supabase → **Authentication → URL Configuration**:

- **Site URL**: `http://localhost:3000`
- **Redirect URLs**: add both:
  - `http://localhost:3000/auth/confirm`
  - `http://localhost:3000/auth/reset-password`

## 6. Start the dev server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) — you should see the landing page.

## Verify it works

1. Go to `/auth/signup` and create an account
2. Check your email and confirm it
3. You should land on `/dashboard/projects`
4. Create a project — it should appear instantly
5. Open the same URL in a second tab — create another project and watch it appear in the first tab (Realtime)
