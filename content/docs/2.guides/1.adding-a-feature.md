# Adding a Feature

The **Projects** feature is the reference implementation. Every new feature you build should follow the same pattern: a composable for data, a page for layout, and components for UI.

## File structure for a new feature

Using "Tasks" as an example:

```
app/
├── composables/
│   ├── useTasksLoader.ts    # useQuery + Realtime subscription
│   └── useTaskActions.ts    # create/update/delete mutations
├── components/tasks/
│   ├── TaskCard.vue
│   ├── TaskDrawer.vue
│   └── TaskDeleteDialog.vue
└── pages/dashboard/tasks/
    └── index.vue
```

## 1. Add the database table

Add a new migration in `supabase/migrations/` and run it in the Supabase SQL editor:

```sql
create table public.tasks (
  id          uuid default uuid_generate_v4() primary key,
  user_id     uuid references auth.users(id) on delete cascade not null,
  title       text not null,
  done        boolean default false not null,
  created_at  timestamptz default now() not null,
  updated_at  timestamptz default now() not null
);

alter table public.tasks enable row level security;
alter table public.tasks replica identity full;
alter publication supabase_realtime add table public.tasks;

create policy "Users can manage own tasks" on public.tasks
  for all using (auth.uid() = user_id) with check (auth.uid() = user_id);

create trigger on_tasks_updated before update on public.tasks
  for each row execute procedure public.handle_updated_at();
```

## 2. Add the type

In `types/index.ts`:

```ts
export interface Task {
  id: string
  user_id: string
  title: string
  done: boolean
  created_at: string
  updated_at: string
}
```

## 3. Create the loader composable

Copy `useProjectsLoader.ts` → `useTasksLoader.ts` and replace `projects` with `tasks`.

## 4. Create the actions composable

Copy `useProjectActions.ts` → `useTaskActions.ts` and adapt the mutations for your fields.

## 5. Add the page and components

Copy the projects page and components, rename, and adapt. The drawer, delete dialog, and card follow the same slot/emit patterns.

## 6. Add the nav item

In `DashboardSidebar.vue`, add to the `navItems` array:

```ts
{ label: 'Tasks', icon: 'i-lucide-check-square', to: '/dashboard/tasks' }
```
