# Introduction

**SaaS Jump** is a production-ready Nuxt 4 boilerplate for launching SaaS products fast. Instead of spending weeks wiring up auth, a database, a dashboard shell, and deployment — you clone this and start building your actual product on day one.

## What's included

- **Authentication** — Email/password signup, login, email confirmation, forgot password, reset password. All flows wired end-to-end with Supabase.
- **Database & RLS** — Supabase Postgres with row-level security. Your users' data is isolated by default.
- **Dashboard shell** — Sidebar navigation, top bar with user menu, and a responsive layout ready for your features.
- **Account settings** — Update display name, avatar, change password, and delete account.
- **Projects (example feature)** — Full CRUD with a rich-text editor, optimistic updates, and Realtime sync across tabs. This is the pattern to follow when you add your own features.
- **Landing page** — Hero, features section, and this documentation — ready to customise.
- **Vercel-ready** — Deploy in minutes with the Nitro Vercel preset.

## Tech stack

| Concern | Choice |
|---|---|
| Framework | Nuxt 4 |
| UI | Nuxt UI v4 (Radix Vue + Tailwind v4) |
| Rich text | TipTap via `UEditor` |
| Backend / Auth | Supabase |
| Data fetching | TanStack Query v5 |
| UI state | Nuxt `useState` |
| Deploy | Vercel |
